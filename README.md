# Todo App — DripCode Starter

Build a Todo app with vanilla JavaScript and LocalStorage. This is the
starter code for the [DripCode Build Projects](https://skill-grid-weld.vercel.app/projects/todo-app) Todo App project.

## What you will build

- Add, complete, delete and filter tasks
- Data that survives a page refresh (LocalStorage)

## Run it

Open `index.html` in your browser. No build step, no install.

## Files

- `index.html` — the page structure (input, Add button, list)
- `style.css` — basic styling
- `app.js` — your logic goes here (currently a stub — `// TODO` marks the spots)

## Steps

Follow the steps on the [project page](https://skill-grid-weld.vercel.app/projects/todo-app). Each step links to the tutorial.

No solution code is included — you write it.
